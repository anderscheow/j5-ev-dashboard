## 与收据的对比

充电分析以车主真实的 PLN Mobile 收据为基准校准：

| 充电记录           | 仪表盘                | 收据                  | 吻合度  |
| ------------------ | --------------------- | --------------------- | ------- |
| 58 → 100 %         | 28.9 kWh / Rp 73,491  | 28.94 kWh / Rp 73,521 | 99.9 %  |
| 35 → 80 %          | 29.1 kWh / Rp 73,981  | 29.23 kWh / Rp 74,273 | 99.6 %  |

直流充电效率按 SoC 建模（充到 100 % 的损耗比充到 80 % 更大），并根据两张收据校准。可用电池容量约 58.9 kWh。

充电规划器预测的是你在电表处实际要付的费用，并已对照一张真实的 PLN Mobile SPKLU 收据验证：

| 应用中的充电规划器 | 真实的 PLN Mobile 收据 |
| :---: | :---: |
| ![充电规划器估算](../screenshots/accuracy-app.png) | ![PLN Mobile SPKLU 收据](../screenshots/accuracy-receipt.png) |

应用估算电表处需购买 **58.2 kWh**，单价 **Rp 2,540/kWh**；收据显示实际输送 **57.34 kWh**，综合单价同为 **Rp 2,540/kWh**。每 kWh 的价格完全一致，电量误差约 1.5 %（收据对应的充电在充满前稍早停止）。退款计算也吻合：购买 Rp 152,448，实际使用 Rp 145,694。
